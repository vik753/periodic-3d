# ADR 0005 — Рендеринг: один холст, инстансинг, кадры по требованию

Статус: принято, 2026-10-10.

## Контекст

Бюджеты плана: 60 кадров в секунду на ноутбуке со встроенной графикой, не больше 100
вызовов отрисовки за кадр, плавные прерываемые переходы.

## Решение

- Одно полотно `<Canvas>` на всё приложение. Сцены — группы объектов в одном мире;
  переход между сценами — полёт камеры (camera-controls).
- Таблица: 118 плиток — один InstancedMesh; подписи — второй InstancedMesh с атласом
  подписей на canvas (один вызов отрисовки на все символы). Итого 2 вызова.
- Атомы и связи молекул — по одному InstancedMesh; связи разбиты на половинки цвета
  своих атомов.
- `frameloop="demand"`: кадр рисуется только при изменениях. Анимированные сцены
  включают непрерывную отрисовку хуком `useKeepRendering`.
- Анимации меняют объекты в `useFrame` через ref, без `setState` на каждый кадр.
- Плотность пикселей ограничена 1,75.

## Последствия

- Простая таблица на «ленивом» цикле почти не тратит батарею.
- Текст на 3D-объектах — только через атлас или troika-текст для единичных подписей.

## Альтернативы

- Отдельный холст на каждую сцену: перезапуск WebGL-контекста и рывок при переходе.
- drei `<Text>` на каждый символ: 118+ вызовов отрисовки.
