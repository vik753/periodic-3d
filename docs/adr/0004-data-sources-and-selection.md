# ADR 0004 — Источники данных и отбор соединений

Статус: принято, 2026-10-10. Основано на замере из CI (ветка `ci-results`, `probe/`).

## Контекст

Замер 2026-10-10 показал:

- Все источники доступны из GitHub Actions. Исключение: OPTIMADE у COD отвечает 501.
- В Wikidata 1,43 млн записей с химической формулой (P274). Из них 27 950 имеют статью
  в русской, украинской или английской Википедии; 23 387 из них имеют PubChem CID.
- Медиана — 87 соединений на элемент. Без соединений — сверхтяжёлые элементы от Db
  до Lv. Пар элементов с 5+ соединениями — 826.
- У 72% случайных соединений с CID есть готовое 3D в PubChem. Пакетный запрос SDF на
  несколько CID работает.
- OPTIMADE у Materials Project отдаёт структуры без ключа, включая поле `_mp_stability`.
- Формулы в Wikidata записаны с юникодными индексами (H₂O); 1,5% формул не разбираются
  (полимеры, переменный состав).

## Решение

- Набор v1 — соединения, у которых есть статья хотя бы в одной из Википедий RU/UK/EN
  (~28 тыс.). Это естественный фильтр известности.
- Рейтинг известности — число языковых версий Википедии (sitelinks).
- Названия RU/UK/EN — метки Wikidata; описания — вступления статей Википедии
  (CC BY-SA, со ссылкой на статью).
- 3D молекул: PubChem 3D (SDF); если его нет — RDKit по SMILES (ETKDG); если и это не
  удалось — плоская схема.
- 3D кристаллов: Materials Project через OPTIMADE по приведённой формуле; берём самую
  стабильную структуру и строим конвенциональную ячейку через spglib.
- Набор GNoME не используем для известных соединений (CC BY-NC). С 2026-10-11 он
  подключён отдельным слоем «Предсказанные материалы» (ADR 0007). Каждая запись хранит
  источник и лицензию.
- Массовые данные берём пакетными запросами с паузами (PubChem — не больше 5 запросов в
  секунду) и кэшируем сырые ответы.

## Уточнение после первых срезов (2026-10-10)

Срез H, O, Fe показал записи, которые не являются соединениями. Правила отбора:

- Не берём сами элементы (класс Q11344), химические группы (Q141501897: гидроксил),
  одиночные атомы и атомные ионы (тритий, H⁺, Fe³⁺). Их место — сцена элемента.
  Аллотропы с формулой из одного атома (алмаз, графит) оставляем.
- Ионы (NH₄⁺, SO₄²⁻) оставляем и рисуем только как молекулы, без кристаллов.
- Минералы (класс Q12089225) всегда показываем как кристалл.
- Молекулу показываем кристаллом только тогда, когда кристалл собран из этих же
  молекул: лёд для воды подходит, твёрдый H₂O₂ для радикала OH — нет. Проверка —
  поиск связанных фрагментов в периодической ячейке.
- В минеральных формулах убираем степени окисления: Fe²⁺Fe³⁺₂O₄ → Fe₃O₄.
- Ячейку стандартизуем с допуском 0,1 Å: расчётные структуры немного искажены, а
  пользователю нужна учебная симметрия (ОЦК-железо, гематит).
- Большие молекулы (больше 150 тяжёлых атомов) получают плоскую схему.
- GNoME: OPTIMADE у Materials Project не сообщает происхождение записи. Поэтому среди
  структур в пределах 0,02 эВ/атом от самой стабильной берём запись с наименьшим номером
  mp-id. Старые записи — известные экспериментальные структуры (ICSD); новые включают
  машинные кандидаты, в том числе GNoME (CC BY-NC). Для известных соединений это
  исключает GNoME и заодно даёт «учебные» структуры.

## Уточнение после полной сборки (2026-10-11)

Полная сборка дала 27 237 соединений, 3D у 23 245 (85%). Без 3D остались три группы.

- **Соли и гидраты** (2 092 записи, например ацетат натрия, гипохлорит натрия). SMILES из
  нескольких частей: `CC(=O)[O-].[Na+]`. Теперь RDKit строит каждую часть отдельно, а
  программа ставит части рядом: противоион — у атома с противоположным зарядом, вода — у
  атома O или N. Больше 16 частей — без 3D (берлинская лазурь).
- **Записи без SMILES** (1 742). Берём SMILES из Wikidata: сначала изомерный (P2017),
  потом канонический (P233). Для известных групп изомеров (глюкоза, ксилол, бутанол)
  берём типичного представителя из списка `REPRESENTATIVE_SMILES`.
- **Белки, антитела, полимеры.** Формулы больше 1000 атомов не берём: 3D-модели нет, а
  формулы в Wikidata часто ошибочны (у гемоглобина «Fe4321»). Таких записей 35.

## Последствия

- Элементы без соединений (Db–Lv) показывают только модель атома и честную подпись.
- Для украинских названий элементов используем современную номенклатуру (Гідроген,
  Оксиген, Ферум…) — список исключений в конвейере.

## Альтернативы

- Все соединения PubChem (более 100 млн): нет смысла для обзора, нет названий RU/UK.
- COD как основной источник кристаллов: нет рабочего фильтра по формуле в OPTIMADE;
  вернёмся к нему для минералов позже.
