# Блокеры

Здесь — вопросы и действия, которые может решить только заказчик.
Пока блокер открыт, работа идёт по другим задачам.

## Открытые

- **Q.2 Метка «структура из эксперимента / только расчёт»** (с 2026-10-11, необязательно).
  OPTIMADE у Materials Project не сообщает, есть ли у кристалла экспериментальный источник
  (ICSD). Это знает только MP API, а ему нужен бесплатный ключ. Действие заказчика:
  1. Войти на https://next-gen.materialsproject.org (через Google или GitHub).
  2. Открыть свой профиль → API → скопировать ключ.
  3. На GitHub: репозиторий → Settings → Secrets and variables → Actions →
     New repository secret. Name: `MP_API_KEY`, Secret: ключ.
  Ключ не пишите в чат и не храните в коде. Без ключа карточка пишет честно:
  «структура Materials Project, расчёт DFT».
