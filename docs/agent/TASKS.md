# Список задач

Правило: берём первую незакрытую задачу сверху. Задачу закрываем, только когда её
проверка прошла.

## Этап 0 — подготовка и проверка рисков

- [x] S0.1 Каркас репозитория: CLAUDE.md, README, docs, .gitignore, LICENSE.
- [x] S0.2 CI: базовый workflow, проверка, что workflow-файлы можно пушить.
- [x] S0.3 Ветка `ci-results` и скрипт публикации результатов CI.
- [x] S0.4 Замер данных в GitHub Actions: доступность источников, число соединений

- [x] S0.5 ADR: стек, разработка через CI, статический режим и API, источники данных.
- [x] S0.6 Lock-файлы: CI сам создаёт package-lock.json и uv.lock и коммитит их

- [x] S0.7 3D-прототип: таблица, полёт камеры, одна молекула, один кристалл.
- [x] S0.8 Деплой прототипа на GitHub Pages и скриншоты из CI.
- [ ] S0.9 Отчёт заказчику по этапу 0.
