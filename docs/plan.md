# План проекта «Таблица Менделеева 3D»

Утверждён заказчиком 2026-10-10. Полная версия — документ «План проекта «Таблица
Менделеева 3D»» в Claude. Здесь — рабочая выжимка для разработки.

## Цель

Веб-приложение: 3D-таблица Менделеева с «провалом» в элемент, светящимися лучами-связями
и облаком соединений для нескольких элементов. Быстро, легко, плавно, в 3D.

## Функции MVP

| Функция | Что видит пользователь |
| --- | --- |
| 3D-таблица | 118 элементов в 3D; наведение подсвечивает, клик открывает элемент |
| «Провал» в элемент | Камера влетает внутрь; модель атома, простое вещество, названия RU/UK/EN/латынь |
| Лучи-связи | Красные лучи к элементам-партнёрам; толщина — число соединений; движение вдоль луча |
| Карточка соединения | 3D-модель (молекула или решётка) медленно вращается; подписи атомов, формула, состав, свойства, источник |
| Мультивыбор | Несколько элементов → облако соединений; дополнительные элементы подсвечены другим цветом |
| Режим «только эти элементы» | Переключатель «содержит хотя бы эти» / «состоит только из них» |
| Поиск | По названию и формуле на трёх языках |
| Ссылки и языки | У каждой сцены свой адрес; интерфейс RU/UK/EN |

После MVP: похожесть (векторная модель), фильтры по классам, фото веществ, AI-гид.
Не входят: реакции, белки, учётные записи, VR/AR, нативные приложения.

## Архитектура

Тяжёлое считаем заранее. Конвейер данных (Python, офлайн) собирает версию набора данных.
Онлайн-часть только читает её:

- живой режим: PostgreSQL + pgvector → FastAPI (только чтение) → CDN → браузер;
- статический режим: экспорт ответов API в JSON → GitHub Pages / любой CDN → браузер.

Фронтенд: один 3D-холст React Three Fiber, панели — HTML поверх холста.

## Источники данных

PubChem (органика, 3D), Materials Project и COD (кристаллы), Wikidata (связка
идентификаторов, названия RU/UK/EN, классы), Википедия (описания), Wikimedia Commons
(фото, после MVP), ElementEmbeddings (векторы элементов, после MVP).
Набор GNoME исключаем (CC BY-NC).
