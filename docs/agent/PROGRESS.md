## Как читать результаты CI

```bash
git fetch origin "+refs/heads/ci-results:refs/remotes/origin/ci-results"
mkdir -p /tmp/claude-0/ci && git archive origin/ci-results <папка> | tar -x -C /tmp/claude-0/ci
```

Папки: `probe/` (замер данных), `web/` (скриншоты, отчёт о размере, логи),
`data/run/` (логи и summary.json конвейера), `data/latest/` (отчёт и срез набора данных).
