# ADR 0007 — Слой GNoME: предсказанные материалы

Статус: принято, 2026-10-11.

## Контекст

Заказчик решил подключить набор GNoME (Google DeepMind, Merchant et al., Nature 2023)
и держать приложение бесплатным и некоммерческим навсегда. Лицензия данных GNoME —
CC BY-NC 4.0: можно использовать с указанием авторства и без коммерческой цели.

Замер в CI (workflow `probe-gnome`, 2026-10-11):

- 554 054 материала (`stable_materials_summary.csv`, 151 МБ; версия набора 8/21/24);
- структуры — CIF в `by_id.zip` (455 МБ, 964 МБ без сжатия), все в P1;
- в среднем 22 атома в ячейке (максимум 107); 2–6 элементов, чаще 4–5;
- 3 403 пары элементов; чаще всего встречаются Ho, Tb, Dy, Si, Y;
- компактная запись ячейки — около 650 байт, всего около 360 МБ.

## Решение

1. **Отдельный слой.** Материалы GNoME никогда не смешиваются с известными соединениями.
   На сайте это «Предсказанные материалы», свой цвет (фиолетовый), пометка
   «предсказано расчётом, не проверено экспериментом», атрибуция и лицензия.
2. **Отдельная сборка.** Команда `p3d-pipeline gnome` и workflow `gnome` собирают
   архив `gnome-<версия>.tar.gz` и публикуют релиз. Файл `data/GNOME` указывает,
   какой релиз использует сайт. Сборка известных соединений от GNoME не зависит.
3. **Компактная структура.** Ячейка — 6 параметров (a, b, c, α, β, γ), атомы —
   `[Z, x·10⁴, y·10⁴, z·10⁴]`. Изображение (атомы на гранях, связи) браузер строит сам.
4. **API.** Таблицы `materials` и `material_pairs`. Эндпоинты отдают «пачки»:
   `/materials/shard/{три hex-символа id}` (4 096 пачек по ~135 материалов),
   `/materials/by-element/{символ}` (строки `[id, формула, Z…, энергия распада]`),
   `/materials/pairs` (число материалов у пары). Статический экспорт пишет те же
   ответы в файлы — так оба режима данных остаются одинаковыми (ADR 0003).
5. **Хостинг.** Сайт с GNoME весит около 600 МБ (лимит GitHub Pages — 1 ГБ). Публикация
   переходит с ветки `gh-pages` на `actions/deploy-pages`: артефакт вместо коммита,
   история git не растёт.

## Последствия

- Лучи и облако получают переключатель «+ предсказанные»; у пары элементов появляется
  вкладка «Предсказанные».
- Приложение должно оставаться некоммерческим (без рекламы и платного доступа), пока в
  нём есть данные GNoME. Это записано в README и на странице «О проекте».
- Правило выбора кристаллов для известных соединений (ADR 0004) не меняется: там
  GNoME по-прежнему исключён, чтобы известное вещество показывало экспериментальную
  структуру.

## Альтернативы

- Отдельный сайт в другом репозитории для данных GNoME: меньше основной сайт, но нужны
  новый репозиторий и токен для публикации между репозиториями.
- Публикация через ветку `gh-pages`: каждый деплой добавлял бы ~600 МБ в git.
- Только живой API без статики: нужен постоянный сервер, демо перестало бы быть
  бесплатным.
