# Блокеры

Здесь — вопросы и действия, которые может решить только заказчик.
Пока блокер открыт, работа идёт по другим задачам.

## Открытые

- **G.3 Публикация GitHub Pages через GitHub Actions** (с 2026-10-11). Сайт с GNoME
  весит около 630 МБ, ветка `gh-pages` для него не подходит. Действие заказчика:
  Settings → Pages → Build and deployment → Source: **GitHub Actions**
  (пошагово — docs/DEPLOY.md, раздел A). До переключения сайт обновляется как раньше,
  но без предсказанных материалов.

## Закрытые
