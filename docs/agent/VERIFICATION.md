## Бюджеты скорости

| Метрика | Бюджет | Результат | Итог |
| --- | --- | --- | --- |
| Стартовый JS (gzip) | ≤ 400 КБ | 380 КБ | Да |
| LCP, сеть 4G (9 Мбит/с, 170 мс) | ≤ 2,5 с | 0,85 с ноутбук; 1,07 с телефон (CPU ×4) | Да |
| 3D-таблица готова, 4G | — | 1,7 с ноутбук; 2,0 с телефон | — |
| Вызовы отрисовки за кадр | ≤ 100 | 3–14 во всех 30 сценариях | Да |
| Файл 3D-структуры (gzip), 95% соединений | ≤ 20 КБ | 1,4 КБ (максимум 5,8 КБ) | Да |
| API без кэша, p95, 4 параллельных запроса | ≤ 300 мс | 14–66 мс по эндпоинтам | Да |
| API без кэша, 32 параллельных запроса | — | p95 0,73 с при 115 запросах/с (общие 4 vCPU с генератором нагрузки) | Предел пропускной способности; CDN снимает нагрузку |
| Переходы 0,8–1,4 с, прерываемые; без полёта при «уменьшить движение» | Да | camera-controls, smoothTime 0,55 с; при reduced motion — мгновенно | Да |
| Доступность: клавиатура, контраст AA | Да | список элементов для клавиатуры (`keyboard-index`), фокус-кольцо; контраст текста 8,5 : 1 | Да |
| FPS: ноутбук 60, телефон ≥ 45 | — | В CI нет GPU (программный рендер), реальный FPS не измерить | Нужна проверка заказчиком |

Меры для FPS: инстансинг (вся таблица — 3 вызова отрисовки), рендер по требованию
(`frameloop="demand"`), адаптивный pixel ratio (AdaptiveQuality), ленивая загрузка частей
сцены.

## Данные и лицензии

- 27 202 соединения со статьёй в Википедии RU/UK/EN; 3D у 25 554 (94%); 1 997 пар.
- 3D-модели: PubChem 15 403, Materials Project 4 716, RDKit 5 435 (из них 47 плоских).
- Описания: EN 23 813, RU 9 752, UK 3 843 (без UK — английский текст с пометкой).
- Фото из Wikimedia Commons: 2 245 соединений, 101 элемент; автор и лицензия под фото.
- Каждая запись хранит источник и лицензию; карточка показывает их со ссылками.
- GNoME (CC BY-NC) исключён правилом выбора структуры (ADR 0004).
- Страница «О проекте» (/about) перечисляет источники и лицензии.

## Известные ограничения

- Элементы без соединений в наборе: Ne и сверхтяжёлые (Md–Lv). Это честный результат
  отбора: у них нет соединений со статьями в Википедии.
- 1 648 соединений без 3D (сплавы, смеси, белки, сложные комплексы) показаны «шарами
  состава».
- Украинских названий и описаний меньше, чем русских и английских: так в источниках.
- Реальный FPS на устройствах заказчика нужно проверить вручную.
